Description: This data is a .csv file from Dr.Ben. It is a data set on watershed data. The variables in this data set are id,snowpack_pct_normal,precip_mm,mean_temp_c, and streamflow_index. 

For this analysis, download watershed.csv and put it into your data directory.

Project Purpose:

The purpose of this project is to to fit and diagnose a linear model using matrix computations, which is intended to predict the streamflow index given the predictors of: normal snowpack percentage, precipitation (mm), and mean temperature (degrees Celsius).
